# Bank Loan Analysis Dashboard | Power BI
## 📊 Project Overview
This project is an interactive Bank Loan Analysis Dashboard developed using Microsoft Power BI.
It provides insights into loan applications, funded amounts, amounts received, borrower details, and overall loan performance.
## 🎯 Project Objectives
- Analyze total loan applications
- Track total funded and received amounts
- Understand interest rates and DTI ratios
- Compare good loans and bad loans
- Analyze loan applications by month and state
- Explore loan purpose, term, grade, and employment length
- Review detailed loan records
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Microsoft Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

### Key Performance Indicators
